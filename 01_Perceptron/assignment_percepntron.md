# 📝 Perceptron 실습 과제

> **주제:** Weight · Bias · 데이터 표준화에 따른 퍼셉트론 분류 결과 비교
>
> 본 과제는 단순히 코드를 실행하는 것이 아니라, **퍼셉트론의 주요 요소를
> 직접 변경하고 결과를 비교·분석하는 것**을 목표로 합니다.

------------------------------------------------------------------------

## 🎯 과제 목표

이번 과제를 통해 다음 내용을 확인합니다.

-   Weight 변화가 퍼셉트론의 출력에 미치는 영향
-   Bias 변화에 따른 분류 결과의 차이
-   StandardScaler 적용 여부에 따른 입력 데이터 변화
-   Accuracy, MSE, MAE를 이용한 결과 비교
-   퍼셉트론의 기본 연산 `z = X @ w + b`에 대한 이해

------------------------------------------------------------------------

# 1. Weight 변화에 따른 성능 비교

기본 실습에서 사용한 Weight는 다음과 같습니다.

``` python
w = np.array([0.5, 0.5, 0.5, 0.5])
```

이를 다음과 같이 변경하여 다시 실행하세요.

``` python
w = np.array([0.1, 0.1, 0.1, 0.1])
```

## 📊 결과 비교

  Weight                     Accuracy   MSE   MAE
  ------------------------ ---------- ----- -----
  `[0.5, 0.5, 0.5, 0.5]`                    
  `[0.1, 0.1, 0.1, 0.1]`

-   Weight의 변화가 `z = X @ w + b`에 어떤 영향을 주었는가?
-   결과가 달라졌거나 달라지지 않은 이유는 무엇이라고 생각하는가?

# 3. StandardScaler 적용 여부 비교

기본 실습에서는 다음과 같이 입력 데이터를 표준화했습니다.

``` python
scaler = StandardScaler()
X = scaler.fit_transform(X)
```

이번에는 위 코드를 주석 처리하여 **표준화를 적용하지 않은 상태**로 다시
실행하세요.

``` python
# scaler = StandardScaler()
# X = scaler.fit_transform(X)
```

표준화 적용 전·후의 데이터도 함께 확인하세요.

``` python
print(X[:3])
print("평균:", X.mean(axis=0))
print("표준편차:", X.std(axis=0))
```
