# 📝 Perceptron 실습 과제

> **주제:** Weight · Bias · 데이터 표준화에 따른 퍼셉트론 분류 결과 비교
>
> 본 과제는 단순히 코드를 실행하는 것이 아니라, **퍼셉트론의 주요 요소를
> 직접 변경하고 결과를 비교·분석하는 것**을 목표로 합니다.

------------------------------------------------------------------------

## 🎯 과제 목표

이번 과제를 통해 다음 내용을 확인합니다.

-   Weight 변화가 퍼셉트론의 출력에 미치는 영향
-   Bias 변화에 따른 분류 결과의 차이
-   StandardScaler 적용 여부에 따른 입력 데이터 변화
-   Accuracy, MSE, MAE를 이용한 결과 비교
-   퍼셉트론의 기본 연산 `z = X @ w + b`에 대한 이해

------------------------------------------------------------------------

# 1. Weight 변화에 따른 성능 비교

``` python

```

이를 다음과 같이 변경하여 다시 실행하세요.

``` python

```
